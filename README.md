# 活動抽籤系統

以瀏覽器開啟 `index.html`，或於本目錄執行 `python3 -m http.server 8000` 後造訪 http://localhost:8000。

從 Google 試算表複製含標題的儲存格並貼上，按「分析名單」。必要欄位為「真實姓名」與「您希望參與的獎項類別」；其他欄位可保留於貼上資料，但不使用、不顯示，也不送到伺服器。每一類別可設定抽獎人數、依姓名排除，且預設已中獎者不再參與。可手動標記到場。

姓名相同的報名資料在每一獎項候選池中合併；多選類別按逗號、頓號、分號或換行拆分。資料與結果僅存在當前頁面的記憶體，重新整理或關閉即清除；重新匯入也會清除結果。若需要以電話辨識重複報名、跨類別資格、保留紀錄、匯出或 Google Sheets 網址直接匯入，須先確認活動規則。
